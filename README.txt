WavesDGlab is a set of MATLAB scripts developped to test and study
high-order continuous and discontinuous Galerkin finite elements methods.

How to use it?
--------------

1) Run setup.m in the root directory

2) Run a script in directory 'scripts'

3) Benchmarks are provided in directory 'benchmarks'
