**WavesDGlab** is a collection of MATLAB scripts developed to test and study high-order **continuous Galerkin (CG)** and **discontinuous Galerkin (DG)** finite element methods.

## Getting started

Before running the scripts, configure the path to the Gmsh installation:

1. Copy `setup_default.m` to `setup.m`.
2. Set the `directoryGmsh` variable in `setup.m` to the path of your Gmsh installation.
3. Run `setup.m` from the root directory of the repository.
4. Run one of the scripts located in the `scripts` directory.

## Repository structure

- `benchmarks/` — Benchmark descriptions and associated data, including meshes and reference solutions.
- `output/` — Output files generated by the code.
- `scripts/` — Main scripts used to run the experiments and simulations.
- `sources/` — Finite element routines and core computational components.
- `tools/` — External resources and contributions.
